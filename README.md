# 3D Reverse Engineering Specialist — Personal Portfolio

Website tĩnh song ngữ Việt/Anh, thiết kế responsive, triển khai miễn phí bằng GitHub Pages.

## 1. Cấu trúc
- `index.html`: nội dung và cấu trúc website.
- `assets/css/style.css`: giao diện, màu sắc, responsive.
- `assets/js/main.js`: chuyển đổi Việt/Anh và menu mobile.

## 2. Cá nhân hóa trước khi xuất bản
Mở `index.html` và tìm/thay:
- `YOUR_EMAIL@example.com` → email thật.
- `+84YOURPHONE` và `+84 YOUR PHONE` → số điện thoại/Zalo thật.
- Địa điểm nếu muốn thay đổi.
- Bổ sung ảnh dự án thật, thông tin đào tạo, chứng chỉ và CV.

Các hình đồ họa trong trang dự án chỉ là minh họa giao diện. Hãy thay bằng ảnh dự án mà bạn có quyền công bố. Không đăng dữ liệu hoặc hình ảnh khách hàng khi chưa được phép.

## 3. Đưa website lên GitHub Pages miễn phí
1. Đăng nhập hoặc tạo tài khoản tại https://github.com.
2. Chọn **New repository**.
3. Đặt tên repository là `phamhoanggiang.github.io` (thay `phamhoanggiang` bằng username GitHub của bạn).
4. Chọn **Public**, sau đó tạo repository.
5. Chọn **Add file → Upload files**.
6. Tải toàn bộ nội dung trong thư mục này lên repository (đảm bảo `index.html` nằm ở thư mục gốc).
7. Nhấn **Commit changes**.
8. Vào **Settings → Pages**. Ở mục Build and deployment, chọn **Deploy from a branch**.
9. Chọn branch `main`, folder `/ (root)`, nhấn **Save**.
10. Chờ GitHub triển khai. Website sẽ có địa chỉ `https://phamhoanggiang.github.io` (dùng username thực tế).

Nếu không dùng tên repository dạng `username.github.io`, URL thường có dạng `https://username.github.io/repository-name/`.

## 4. Cập nhật website
Sửa trực tiếp `index.html`, `assets/css/style.css` hoặc `assets/js/main.js` trên GitHub rồi Commit changes. GitHub Pages tự triển khai lại sau vài phút.

## 5. Ghi chú
- Hosting GitHub Pages miễn phí cho website tĩnh public.
- Địa chỉ `github.io` miễn phí; tên miền riêng là tùy chọn và thường phải trả phí.
- Google Fonts cần kết nối Internet; nếu không có mạng, website vẫn hiển thị bằng font dự phòng.
- Website chưa có backend/form nhận tin. Nút email mở ứng dụng email của người xem.
