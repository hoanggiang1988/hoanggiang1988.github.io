1. Kết nối GitHub

Tạo Fine-grained Personal Access Token trong GitHub, chỉ cấp quyền Contents: Read and write cho đúng Repository của website. Token được lưu trong trình duyệt bạn đang dùng; không gửi token cho người khác. Nên đặt thời hạn token và thu hồi khi không còn sử dụng.

Tạo token tại GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Chọn đúng repository và cấp quyền Repository permissions → Contents → Read and write. Không bật quyền Administration.

3. Lưu thay đổi lên website

Sau khi chỉnh sửa các mục, nhấn nút dưới đây để ghi nội dung vào data/content.json trên GitHub. GitHub Pages sẽ tự triển khai lại sau đó vài phút.

Trang quản trị không có mật khẩu riêng. Bảo vệ quyền chỉnh sửa bằng token GitHub; không sử dụng token trên máy tính công cộng và luôn đăng xuất / xóa token sau khi dùng.
